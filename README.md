# Orbit

An original spatial soundscape built with the Web Audio API. Open the [live player](https://npclabs-19.github.io/odyssey-soundscape/) and press **Start listening**. Headphones make the spatial movement easier to perceive.

Four adjustable layers, three presets, movement/space/warmth controls, mono comparison and a 5/15/30/60 minute session timer. Audio begins only after pressing Play and is generated on the device. The technical study and its limitations are in [ANALYSIS.md](./ANALYSIS.md).

No build step or dependencies:

```sh
python3 -m http.server 4174
```

Published from `main` at the repository root to GitHub Pages under NPCLABS-19.
